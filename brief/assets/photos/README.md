## Чего нет (и как обходимся)

Съёмка пока не планируется. Для этих блоков дизайн делаем **без фото**, на типографике и графике, а место под фото оставляем, чтобы потом просто подставить кадры из `../shoot/`:

| Блок | Нет фото | Чем заменить сейчас |
|---|---|---|
| Бар / коктейли | Ни одного коктейля | Карточки-типографика: крупное название, состав, цена, зелёная плашка |
| Чай в чашке | Только полка | Фото полки + рукописные названия чаёв |
| Гости, атмосфера вечером | Нет людей | Фото зала 07, 06 + отзывы гостей крупным текстом |
| Вход снаружи | Только куб ночью | Куб 08 + карта + текстовый ориентир «Batumi View, блок B» |
