> Этот список на случай, если владелец решит доснять. Готовые кадры кладём сюда с именами из таблицы и подставляем в сайт на место графических заглушек, без переделки дизайна.

Сейчас нет ни одного кадра с напитками и гостями. Для направления **Night Glow** пригодится следующее.

## Стиль (как у существующих фото)
- Низкий ключ: тёмные кадры, холодные сине-серые тени, тёплые пятна света от бра и подсветки
- Зелёный только от бренда (вывеска, логотип, зелёный диван), без цветных гелей и неона
- Фон чистый: без случайных вещей, пакетов, проводов

## Формат
- Фото: **JPG в полном разрешении** (или RAW), не из мессенджера
- Для каждого ключевого кадра два варианта: **горизонтальный 16:9** (десктоп) и **вертикальный 4:5** (мобайл)
- Видео: **5–10 секунд, горизонталь и вертикаль, без резких движений**, чтобы можно было зациклить в hero
- Люди в кадре только с их согласия. Если лица не нужны, снимать руки, силуэты, спины
